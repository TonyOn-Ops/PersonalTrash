As a user with an EliteBook, I've ended up in a long fight with HP's bloated analytics bullshit.

This "tool" was created in order to boot together with Windows and avoid letting HP reinstall its parasite.
I created this .bat file in early 2026 and updated it in order to block the new WXP service.

Let's start with the guide:

1) Download StartHPBlocker.vbs and killinsight.bat
2) Edit the .vbs file --> On the 2nd line, "C:\Users\User\AppData..." change "User" with your personal username
3) Press Windows + R
4) Type: shell:startup
5) Copy and paste the files you downloaded in step 1
6) Open Control Panel and select "Uninstall a Program" under Programs
7) Uninstall every single HP Insight software
8) Restart Windows

After boot, within about a minute, Windows should start the .bat file.
I've uploaded a picture with the result at the end of the guide.

The .bat file uses about 1.5MB of RAM in Task Manager.
